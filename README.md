# Barbara069 / Private Company Comparables Research

[Open the research website](https://barbara069.github.io/private-company-comparables-research/).

Every company has one full public research profile. The original-560/global-universe list filters do not change that profile. General facets, industry facets, segment evidence, source dates and source links remain available in the research tabs.

Only Public Comps simulates an original target as private. Its target inputs come from a separate allowlisted snapshot: official website business text plus original instructor Revenue, EBITDA and derived Debt. SEC/vendor target research is excluded from that comparison. Public candidate research is unrestricted.

Source passages and typed API fields are retained with provenance. Many observations still require entity, date, scope, meaning and independent-source review. Unknown fields remain unknown; preliminary scores are not final recommendations or calibrated probabilities.

Original input files, complete CSVs and the research Notebook belong in the personal private data repository, not this public website repository. No API credentials are embedded in the site.
